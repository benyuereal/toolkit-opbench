# 题目模板

> 复制本目录为 `tasks/<family>-<op>-<tier>/`，改三个文件。

## task.md 应该写什么

1. **背景**：实际场景，不要抽象成数学题
2. **要回答的**：一句话问题 + 必须包含的交付项
3. **约束**：预算 / 不许做什么 / 没验证的要标"未验证"
4. **评判标准**：让他知道什么算答对

**不要写**：答案、我们已有的结论、任何 `expect.md` 里的内容。

## expect.md 应该写什么

1. 当前已知结论 + 依据
2. 合格的回答长什么样
3. 不合格的回答（尤其是"看起来合理但错"的）
4. **一个例外**：如果 agent 拿出可复现的反证，以它为准

## check.py（可选）

能自动判的才写。典型能自动判的：
- 声称的 `import_path` 是否真的存在
- 产出的 `results/*.json` 是否有必需字段
- 声称的 ratio 是否与 results 里的数字一致

判不了的（比如"机制解释是否成立"）留给人工或评分器规则。
