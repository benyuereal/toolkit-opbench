# 任务：本机有没有可调用的 hadamard 变换 symbol

## 背景

我们在 8 卡 DCU（gfx938）上优化线性注意力类模型（MHC / gated delta net 一类）。
这类模型的快速变换里会用到 **hadamard 矩阵乘法**（Walsh-Hadamard / 随机符号 hadamard）。

团队在整理可复用资产时，有人报告「本地有已优化的 hadamard 实现」。
现在需要确认：**这个说法在本机成立到什么程度？**

结论会直接影响"能不能复用"这件事。

## 要回答的

**本机（含已安装的算子库）有没有一个可直接调用的 hadamard 变换函数？**

要求给出：

1. **结论**：本机在这件事上的真实情况，以及能不能直接拿来用
2. **依据**：你实际搜索了什么（库的 `dir()`、源码、符号表）、贴出关键输出
3. **归属**：它的实现落在哪里、以什么形式存在
4. **替代**：如果要用 hadamard，本机能怎么做
5. **复跑**：给出你跑的命令与脚本位置

## 约束

- 时间预算：**10 分钟**
- 只写你实际验证过的东西。**没验证的写「未验证」，不要推测成结论。**
- 注意 `import` 得到的东西不一定就是你要的那个函数
- 产出写到当前目录的 `report.md`，验证脚本放 `scripts/`，原始输出放 `results/`。

## 评判标准

> 结论要落到「这个能力在本机以什么形式存在、能不能直接用」，
> 而不是停在「有没有这个名字」。
> 只说没有/有，而没说清它实际在哪、怎么用，视为结论不完整。
