# 任务：稀疏 MLA 前向的实现选型与达成率

## 背景

我们在 8 卡 DCU（gfx938，Hygon BW1100）上跑 DeepSeek 系模型的推理。
decode 阶段用的是 **DSA（DeepSeek Sparse Attention）**：每个 query 不再看全量 KV，
而是只在 top-k 个历史 token 上做 MLA。

```
score[i,h,j] = q[i,h,:] · kv[indices[i,0,j], :] * sm_scale    j ∈ [0, topk)
out[i,h,:]   = softmax_j(score[i,h,j]) · kv[indices[i,0,j], :512]
```

张量形态：

| 张量 | 形状 | dtype |
|---|---|---|
| `q` | `[S, H, 576]` | bf16 |
| `kv` | `[SKV, 1, 576]` | bf16 |
| `indices` | `[S, 1, TOPK]` | int32 |
| `out` | `[S, H, 512]` | bf16 |

注意 `q`/`kv` 都是 **576 维**，但输出只有 **512 维**。

## 要回答的

**在本机跑这个稀疏 MLA 前向，应该用哪个实现？它的达成率是多少？**

具体要给出：

1. **落到的实现**：`库.函数`、版本、**完整调用签名**
2. **实测耗时**：至少两个 S 档位
3. **有效流量**：这段实际访存多少字节，怎么算的
4. **达成率**：分母取自哪里、为什么可信
5. **正确性**：你怎么确认它跟参考语义一致（尤其是边界情况）
6. **复跑**：给出命令与脚本位置

## 约束

- 时间预算：**30 分钟**
- 只写你实际验证过的东西。**没验证的写「未验证」，不要推测成结论。**
- 计时必须用 GPU event（`torch.cuda.Event`），**不许用 wall clock**。
- 每轮计时前要处理 L2 缓存（本机 L2 = 8 MB）。
- 产出写到当前目录的 `report.md`，验证脚本放 `scripts/`，原始输出放 `results/`。
