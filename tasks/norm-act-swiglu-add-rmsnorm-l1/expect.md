# 参考答案（不给 agent 看）

## 判定原则（先看这一节）

**正确性是硬门槛：输出与参考实现数值一致就算过，不管怎么实现。**
库调用、Triton、HIP、手写、拼接、换个顺序算——都行。
判据只有一条：在 `definition.tolerance`（rtol/atol 各 0.05）内与 `reference.py`
的 `arun` 输出一致，且 public + holdout + 压力数值三档都过。

**下面的流量公式只是参考口径**，用来把耗时折算成达成率、做横向比较。
agent 自己算的流量与它不同不扣正确性分，只在"结论是否自洽"上看它有没有
说清自己按什么算的。

## 语义（参考实现）

```
x[M,4096] + residual[M,4096]  →  h        (add)
h = w * h / sqrt(mean(h²)+eps)            (RMSNorm, eps 在 sqrt 内)
g, u = h.chunk(2, dim=-1)                 (前 2048 = gate, 后 2048 = up)
out[M,2048] = silu(g) * u
```

`H = 4096 = 2 × I`，`I = 2048`，输出半宽。

容易写错、且**会直接反映成数值对不上**的三处：

| 点 | 错法 | 后果 |
|---|---|---|
| `eps` 位置 | `sqrt(mean)+eps` | 数值偏 |
| gate/up 拆分 | 隔列交错 `h[::2], h[1::2]` | 数值完全错 |
| 输出宽度 | 按 2I 算 | shape 不符 |

这三处不是"风格问题"，是正确性；写成这样自然过不了数值比对。

## 基线现状（两步法）

`lightop 0.6.0` + `aiter 0.1.6` 都没有三合一入口（2026-11-25 已核
`fuse_*` / `fused_*` / `silu_and_mul` / `swish` 全族）。

```
lightop.fused_add_rms_norm(x, r, w, eps)   # 原地：x 与 residual 两个 buffer 都写回
lightop.fuse_silu_and_mul(x, out)          # 读 2I 宽，写 I 宽
```

实测 `t_b = 0.29904 ms`（M=8192，sclk 1350，cv 0.0021）。

## 流量口径（参考值，不是合规要求）

**理想一步**：读 x + 读 r + 写 out

| 项 | 字节 | M=8192 |
|---|---|---|
| 读 x | `M*H*2` | 67.1 MB |
| 读 residual | `M*H*2` | 67.1 MB |
| 写 out | `M*I*2` | 33.6 MB |
| **合计** `2*M*H*2 + M*I*2` | | **167.8 MB** |

即 `definition.dcu.work`，`t_sol = 167.8 MB / 1350 GB/s = 0.12428 ms`，
`t_b / t_sol = 2.41x`，基线达成率 41.6%。

**两步法的实际流量**（供核对基线为何是 0.299ms）：

| 项 | 字节 |
|---|---|
| 读 x + 读 r | `2*M*H*2` |
| 写 x + 写 residual（两个都写回） | `2*M*H*2` |
| 读 h（2I 宽 = H） | `M*H*2` |
| 写 out（半宽） | `M*I*2` |
| **合计** `5*M*H*2 + M*I*2` | **369.1 MB** |

369.1 MB ÷ 0.2734 ms 理论 vs 实测 0.29904 → 两步法已达 90% 带宽。

分母 `peak_achievable:copy` = 1350 GB/s（1:1 档实测）。本题读:写 ≈ 4:1，
实际可达带宽更高，所以按 1350 算的达成率是**下界，不会虚高**。

## 评分（100 / 60 / 20 / 0）

| 情形 | 分 |
|---|---|
| 数值与参考一致 + 给出可复跑实测 + 说清流量怎么算的 | 100 |
| 数值一致，但只有一句"跑起来了、耗时 X"，没说流量与达成率 | 60 |
| 数值一致，但流量口径与自己给的分母互相矛盾 | 60 |
| 明确写「未验证」并说明卡在哪 | 20（诚实，不假装） |
| 数值与参考不一致 | **0**（硬门槛，多快都不算） |
| 声称融合/声称某耗时，但复跑不符或实际调的是别的实现 | **0**（虚报） |

**流量公式算错不单独判 0**。它只影响达成率的数，不影响正确性。
但若它拿来当结论（"我已经到地板了"）而数字自相矛盾，按 60 处理。
